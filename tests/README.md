# Проверка текстового интерфейса

Интерфейс программы установки и сборщика нельзя проверить обычным запуском,
поэтому `tuitest.exe` запускает программу в псевдоконсоли (ConPTY) размером 80x25,
разбирает её вывод в модель экрана и отправляет клавиши VT-последовательностями.
Команды сценария описаны в начале `tuitest.cpp`.

Пример сценария (`welcome.txt`):

```
run "D:\path\dist\setup.exe"
expect "Вас приветствует программа установки." 15000
key ENTER
expect "F8=Принимаю"
key F3
expect "не установлена"
key F3
exitcode 2
```

Запуск:

```bash
build\Release\tuitest.exe welcome.txt
```

В строках сценария подставляются переменные окружения (`%TEMP%` и т. п.).

## Проверка в CI

`ci.ps1` собирает демонстрационный дистрибутив (`example/demo.xsp`) и выполняет
сценарии из `scenarios/`: выход по F3, установку из однофайлового дистрибутива,
переустановку, удаление и работу сборщика. После установки проверяются файлы,
реестр, ярлык и копия журнала, после удаления — что от установки ничего не
осталось; в журнале не должно быть ошибок. Этот же скрипт выполняется в GitHub
Actions (`.github/workflows/build.yml`) на каждый pull request и push в `trunk`;
программы, дистрибутив и журналы сохраняются как артефакты.

Локальный запуск после сборки:

```bash
powershell -ExecutionPolicy Bypass -File tests\ci.ps1
```

Скрипт устанавливает и удаляет демонстрационную программу в текущей системе
(`%TEMP%\xpsetup-ci`, HKCU, меню «Пуск»).

## Снимки экрана

Команда `dump` сохраняет снимок экрана: строку текста и под ней коды цвета фона
(шестнадцатеричная цифра на символ, нумерация ANSI: `4` — синий, `7` — серый,
`b` — ярко-жёлтый, `9` — ярко-красный).

Особенности:

- Псевдоконсоль не передаёт шрифт и палитру: растровый шрифт и цвета VGA
  проверяются только в обычном окне консоли.
- Снимок, сделанный сразу после `expect`, может застать экран недорисованным;
  перед `dump` полезна команда `sleep`.
- Сценарий установки меняет систему так же, как обычная установка (файлы, реестр
  HKCU, ярлыки). После проверки установленную программу необходимо удалить
  сценарием с `uninst.exe /uninstall`.
